## 🎯 Mastery Definition

You've mastered the system when:
- [ ] You run the leverage loop instinctively on new tasks
- [ ] Your prompt library has 20+ battle-tested prompts
- [ ] You've taught the loop to at least 3 people
- [ ] Your stop conditions catch real issues before they ship
- [ ] You have a monthly deep-dive habit from the Leverage Library
- [ ] You've contributed at least one improvement to the repo
- [ ] Others come to you for leverage advice

**Mastery is a practice, not a destination. Keep looping.**
