# Quick Reference Card — Stop Conditions

**Print this. Keep at your desk. Use every prompt.**

---

## The 3-Question Test

Before you run ANY prompt, ask:

| Question | Yes? | No? → Rewrite |
|----------|------|---------------|
| **1. Observable?** Can someone else verify without reading your mind? | ☐ | Add concrete check |
| **2. Falsifiable?** Can you clearly FAIL it? | ☐ | Make it binary |
| **3. Real Risk?** Targets what actually goes wrong, not a proxy? | ☐ | Find the real risk |

**All 3 = ✅ | Any ❌ = Rewrite before you run.**

---

## Good vs. Bad Stop Conditions

| ❌ BAD (Vague/Proxy) | ✅ GOOD (Observable + Falsifiable + Real Risk) |
|----------------------|------------------------------------------------|
| "Until it feels right" | Every claim has a source I can name |
| "Until I'm confident" | Every number traces to a doc I trust |
| "Good tone" | Ask is explicit in first 2 sentences |
| "High quality" | Every claim links to a source I can name |
| "Until it's done" | 2 unverified claims flagged explicitly |
| "Looks professional" | Would be comfortable with manager reading it |

---

## By Work Type (Copy These)

| Work Type | Copy-Paste Stop Condition |
|-----------|---------------------------|
| **Research Brief** | `Stop when: every factual claim links to a source I can name, and I've flagged the 2 claims I could NOT verify.` |
| **Status Update** | `Stop when: every number traces to a doc/source I trust, and the ask is explicit in the first 2 sentences.` |
| **Draft Email** | `Stop when: it says one clear thing, the recipient knows exactly what to do, and I'd be comfortable with my manager reading it.` |
| **Summary** | `Stop when: nothing important from the source is missing, and nothing in the summary isn't in the source.` |
| **Decision Brief** | `Stop when: every claim sourced; tradeoffs explicit; downside scenario written.` |
| **Meeting Prep** | `Stop when: agenda has decision items; owners named; timeboxes set.` |
| **Creative Work** | `Stop when: time-boxed — 3 passes, then decide.` |

---

## The Pattern

A stop condition is **one sentence** that means "ship it."

**Pattern:** `Stop when: [observable condition] + [falsifiable check] + [real risk target]`

**Examples:**
- `Stop when: every number traces to a doc I trust, and the ask is explicit in the first 2 sentences.` (Status Update)
- `Stop when: every factual claim links to a source I can name, and I've flagged the 2 claims I could NOT verify.` (Research)

---

## How to Use It

1. **Write it FIRST** — before you run the prompt
2. **Put it in the prompt** — as the last line
3. **Check like a checklist** — not a vibe
4. **If it fails** → say which line failed → re-run
5. **If it passes** → ship. No "one more polish."

---

## The Discipline

> Writing the stop condition takes 30 seconds you'll swear you don't have. And sometimes the real job is creative, where "good" is a taste call — in that case your stop condition is "time-boxed: 3 passes, then decide." The discipline is the same: decide the finish before you run, so the machine doesn't decide it for you.
