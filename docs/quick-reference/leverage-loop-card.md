# Quick Reference Card — The Leverage Loop

**Print this. Keep at your desk. Use every time.**

---

## The Loop

```
CAPTURE → STRUCTURE → JUDGMENT → RE-RUN → REPEAT
  │           │           │          │         │
  └─ Dump     └─ Organize └─ You mark └─ Feed   └─ Until stop
     messy     (draft,     what's      judgment  condition
     notes     summarize,  wrong/      back      passes
               rank)       missing     as next
                                  prompt
```

**The key is JUDGMENT.** Most people skip it and wonder why output is mid. The loop only works because a human keeps raising the standard each pass.

---

## Quick Prompt Template

```
CONTEXT: I'm a [role] writing a [status update / follow-up / brief] for [audience].
RAW MATERIAL:
[paste your messy notes]

TASK: Draft a tight version. Then, in a separate section, list the 3 weakest parts of
your own draft and exactly what would make each stronger.

CONSTRAINTS: Plain language. No jargon. Under [X] words.
STOP WHEN: [your stop condition — see below]
```

**Run it. Read the "weakest parts" section. Run again with that feedback pasted in. That second pass is where the quality lives.**

---

## Stop Condition Checklist

```
☐ Observable (someone else could verify)
☐ Falsifiable (you can clearly fail it)
☐ Targets the real risk (not a proxy)
☐ Written BEFORE you start
☐ Checked like a checklist, not a vibe
```

**If any box unchecked → rewrite the stop condition.**

---

## Common Stop Conditions by Work Type

| Work Type | Stop Condition |
|-----------|----------------|
| **Research Brief** | Every claim sourced; 2 unverified claims flagged |
| **Status Update** | Every number traces to doc; ask explicit in first 2 sentences |
| **Draft Email** | Says one clear thing; recipient knows exactly what to do; comfortable with manager reading |
| **Summary** | Nothing important missing; nothing in summary not in source |
| **Creative Work** | Time-boxed: 3 passes, then decide |

---

## The Loop in Practice

| Pass | What Happens | Time |
|------|--------------|------|
| 1 | Capture → Structure → First draft | ~5 min |
| 2 | Judgment → Re-run → Refined draft | ~5 min |
| 3 | Judgment → Re-run → Polish | ~5 min |
| 4+ | Only if stop condition not met | ~5 min |

**Usually 2–4 passes. Not 20.**

---

## The Golden Rule

> **Write the stop condition FIRST. Then run the prompt. Check like a checklist, not a vibe.**
