The 10-Week Curriculum

Four progressive modules building a personal leverage system that compounds. Pick a track, finish it, then add another.

Module Overview

Module 1: Foundations

Weeks 1–2

Mental models → Capture/Structure/Judgment Loop → First recurring prompt. Run the loop on a real task 3× this week. Save the prompt.

  • Leverage Map (20 min)
  • Run Loop 3× (3 × 15 min)
  • Checkpoint: Pass/Fail

Module 2: Core Practices

Weeks 3–5

Stop conditions → Maker-Checker → Recurring prompts → Learning paths. Build your stop-condition library, checked artifact, 5-prompt library, and first retrieval log.

  • Wk 3: 3 Stop Conditions
  • Wk 4: Maker-Checker + 5 Prompts
  • Wk 5: 1 Book Retrieval Log
  • Checkpoint: Portfolio Review

Module 3: Your Track

Weeks 6–8 (Pick ONE)

Apply the system to your domain. Manager: Decision Loop. Writer: Draft-Edit-Publish. Operator: Status-Followup-Handoff. Knowledge Worker: Research-Brief.

  • 1 domain project
  • 1 retrospective
  • Track-specific deliverable

Module 4: Mastery

Ongoing

Advanced prompts → Teach the loop → Monthly deep-dives → Community → Contribute. Your library becomes proprietary IP.

  • Advanced custom prompts
  • Teach Module 1 to a colleague
  • Monthly theme from Leverage Library
  • Share & review peer prompts

Rule of One

Pick ONE track. Finish it. Then add another.

The lead guide carries most of the impact (Great Leads). Spreading across tracks before finishing one dilutes leverage. Complete the project + retro for your chosen track before starting a second.

Each track gives you a complete, working leverage system for that domain. You can always add another track later — and you'll be faster at it because the core loop is already internalized.

Module 4: Mastery (Ongoing)

Advanced Prompts

Build custom prompts for your domain. Your library becomes proprietary IP — the prompts encode your judgment, your voice, your standards.

Teach the Loop

Run Module 1 for a colleague. Teaching = highest-form retrieval (Feynman). You'll find gaps in your own understanding and fix them.

Monthly Deep-Dive

One theme/month from the Leverage Library. Compound the mental models behind the guides: judgment, retrieval, strategy, conversation, discovery.

Community & Contribute

Share a prompt, review a peer's. Social accountability + new patterns. Add a guide, fix a link, improve a template. The repo gets better; you own a piece.
