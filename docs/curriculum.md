# AI Leverage Field Guide — Curriculum Map

**Start here. See the whole journey before you commit.**

## The Promise

You don't need more AI tools. You need a **reliable system** to turn raw AI output into work you can stake your reputation on.

This curriculum takes you from "I paste prompts and hope" → "I run a leverage loop that compounds every week."

**Time to first win:** 20 minutes (Module 1, Exercise 1)  
**Time to working system:** 4–6 weeks (Modules 1–2)  
**Time to role mastery:** 8–10 weeks (Modules 1–3)

### Module 3: Role Tracks (Weeks 6–8)

*Pick ONE. Each track = 2 guides + 1 project + 1 retro.*

| Track | Guides | Project | Retro Question |
|-------|--------|---------|----------------|
| **Manager** | Maker-Checker + Stop Conditions | Run a decision loop on a real decision: capture → structure → judgment → decide | "Where did the loop save me from a bad call?" |
| **Writer** | Loop Prompting + Recurring Prompts | Build a draft→edit→publish pipeline for your content | "Where did the loop make the draft sharper, faster?" |
| **Operator** | Stop Conditions + Recurring Prompts | Build a status→follow-up→handoff pipeline for your week | "Where did the loop prevent a dropped ball?" |

**Each track outcome:** A domain-specific leverage system you use every week.

## Quick Reference: The Leverage Loop

```
CAPTURE → STRUCTURE → JUDGMENT → RE-RUN → REPEAT
  │           │           │          │         │
  │           │           │          │         └─ Until stop condition passes
  │           │           │          └─ Feed judgment back as next prompt
  │           │           └─ You mark what's wrong/missing/off-voice
  │           └─ Run prompt to organize (summarize, group, draft, rank)
  └─ Dump messy raw material (notes, bullets, transcript)
```

**The key is JUDGMENT.** Most people skip it and wonder why output is mid. The loop only works because a human keeps raising the standard each pass.
