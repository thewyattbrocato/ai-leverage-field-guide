# Writer Track

*Build a draft→edit→publish pipeline that compounds. Every piece gets better, faster.*

---

## Why This Track

Writers produce. Newsletter, blog, LinkedIn, internal docs, client deliverables — the
pipeline turns "blank page anxiety" into "ship on schedule."

**Guides:** [Loop Prompting](../guides/loop-prompting.md) + [Recurring Prompts](../guides/recurring-prompts.md)

**Time:** 3 weeks (Weeks 6–8)  
**Outcome:** A content pipeline you use every week.

---

## The Pipeline

```
MONDAY — IDEATION
  Prompt: "Give me 10 angles on [topic] for [audience]. Rank by surprise + utility."
  Output: 1 chosen angle + why

TUESDAY — DRAFT (Loop Prompting)
  Prompt: Loop Prompting template
  Run: Capture → Structure → Judgment → Re-run (2 passes)
  Stop Condition: Every claim sourced; one clear point; under word count; CTA clear

WEDNESDAY — EDIT (Maker-Checker)
  Prompt: Maker-Checker checker prompt
  Output: v2 → ready to publish

THURSDAY — PUBLISH
  Ship it.

FRIDAY — RETRO
  What worked? What was slow? What prompt needs v2.0?
```
