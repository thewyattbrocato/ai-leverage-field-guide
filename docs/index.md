# AI Leverage Field Guide

Practical AI leverage for working professionals, managers, operators, knowledge workers.
Not engineers. Not hype. **More leverage, not more AI.**

This is the long-form companion to the README hub. The hub points you to free resources
across the web. This site is the original, copy-paste part: short guides you can use
today, written from inside real work.

## Start here

If you read nothing else, read these four in order:

1. **[Loop Prompting](guides/loop-prompting.md)**, how to run the same prompt repeatedly
   to converge on quality instead of hoping the first try lands.
2. **[Stop Conditions](guides/stop-conditions.md)**, how to define when AI work is
   actually *done*, so you stop over-iterating and start shipping.
3. **[Maker-Checker](guides/maker-checker.md)**, split drafting (machine) from checking
   (human judgment), and keep the human part sharp.
4. **[Recurring Prompts](guides/recurring-prompts.md)**, build a personal prompt library
   for the work you do every week, so leverage compounds.

## The one idea behind all of it

AI is a **leverage layer**, not a trend. The point is not to use more AI. The point is to
get more output per hour without adding hours, and to keep your judgment in the loop
where it matters. Capture the mess, let the machine structure it, apply your judgment,
and save the loop.

No tool treadmill. No prompt theater. No outsourced judgment.

## How the guides are written

Each guide follows the same shape:

- **Old way**, what most people do.
- **Swap**, the move that adds leverage.
- **What changes**, what actually gets better.
- **Tradeoff**, what you give up or have to watch.

Every guide is original, written in the captain's voice, and grounded in the working
library of business, writing, and thinking books behind this project (see
[reading.md](reading.md) for the full catalog). Ideas from those
books are attributed; the writing is original.
